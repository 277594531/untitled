RSA sign & encrypt

Sign a message with the sender's private key, encrypt it for the recipient's public key, and get one envelope you can send. Everything runs in this page; nothing is uploaded.

This browser has no Web Crypto API here. Open the file from disk or over https in a current Chrome, Edge, Firefox, or Safari.

No keys yet? Generate a signing pair and an encryption pair. They fill the four key fields below.

Keys can be PEM (PKCS#8 or SPKI, plus older PKCS#1 "RSA PRIVATE KEY" / "RSA PUBLIC KEY") or JWK. Passphrase-protected keys are not supported. Use separate key pairs for signing and encryption.
