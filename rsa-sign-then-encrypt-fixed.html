RSA Sign-Then-Encrypt

Browser-only cryptography. This page supports PKCS#1 and PKCS#8 private keys, and SPKI and PKCS#1 public keys.

Supported: BEGIN RSA PRIVATE KEY (PKCS#1), BEGIN PRIVATE KEY (PKCS#8), and BEGIN ENCRYPTED PRIVATE KEY is not supported because a password would be required.
Private-key format: not detected
Supported: BEGIN PUBLIC KEY (SPKI) and BEGIN RSA PUBLIC KEY (PKCS#1).
Public-key format: not detected
Sign first, then encrypt: the signature is computed over the original message, then the message + signature are encrypted with AES-GCM. The AES key is wrapped with the recipient's RSA-OAEP public key.
  1. UTF-8 encode the original message.
  2. Sign the original message with the sender RSA private key.
  3. Generate a random 256-bit AES-GCM key and 96-bit IV.
  4. Build a payload containing the original message and its RSA signature.
  5. Encrypt that payload with AES-256-GCM.
  6. Wrap the AES key with the recipient RSA public key using RSA-OAEP/SHA-256.
  7. Return the JSON envelope.
